1. Overview

  This project is dedicated to developing a visualization tool for analyzing the financial performance of a transport and stevedoring Joint Stock Company (JSC). The tool focuses on providing insights through three core financial reports:

    1. Balance Sheet
    2. Profit and Loss Statement
    3. Cash Flow Statement
These reports will be visualized using interactive charts, dashboards, and KPIs to deliver both an overarching view and detailed analysis of the company’s financial health.

2. Objectives

Financial Performance Analysis: Provide a clear and concise visualization of the company's financial performance through the integration of key financial metrics and trends.

Capital Efficiency Assessment: Analyze and conclude the company's capital efficiency based on financial data and KPIs.

3. Features

* Interactive Dashboards
    * Visualize key metrics and trends from financial statements.
    * Drill-down capabilities for detailed analysis.
* Charts and Graphs
    * Line charts for trend analysis.
    * Pie charts for distribution insights.
    * Bar charts for comparison and categorical data.
* Key Performance Indicators (KPIs)
    * Return on Equity (ROE)
    * Debt-to-Equity Ratio
    * Net Profit Margin
    * Current Ratio
    * Cash Conversion Cycle
* Capital Efficiency Metrics
    * Analyze and conclude how effectively the company utilizes its capital to generate revenue and profits.
4. Data Requirements

* Financial Statements: Historical and current data for the balance sheet, profit and loss statement, and cash flow statement.
* Operational Metrics: Data on revenue sources, operational costs, and capital structure.

5. Tools and Technologies
* Programming Language: Python (e.g., Pandas, Matplotlib, Seaborn, Plotly, Dash)
* Database: Data collection from CafeF news
* Visualization Frameworks: DAX for calculate some KPIs, Power BI for dashboards
* Data Processing: Excel/CSV integration and Google colab python, Power Query for preprocessing

6. Deliverables
* Interactive dashboards with charts summarizing financial reports.
* Detailed KPI analysis for financial performance tracking.
* Final conclusions on the company’s capital efficiency.

7. Usage
* Input Financial Data: Upload financial statement data (Excel).
* View Dashboards: Explore interactive visualizations and trends.
* Analyze KPIs: Monitor financial health through calculated indicators.
* Capital Efficiency Report: Review final insights on capital efficiency.
